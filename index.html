Multicast, QoS & L2 Knowledge Base

ENCOR 350-401 v1.2 Domain 3 (Infrastructure) & Domain 1 (Architecture) reference with full acronym expansions and operational definitions.

IPv4 Multicast (IGMP & PIM)

PIM Sparse Mode vs. Dense Mode (Pull vs. Push)

PIM (Protocol Independent Multicast): Uses the existing unicast routing table (OSPF, EIGRP, BGP, static) for loop prevention without running its own routing protocol. PIM Sparse Mode (PIM-SM): Uses a pull model—routers only forward multicast traffic down interfaces that explicitly request it via PIM Join messages toward a Rendezvous Point (RP), keeping links clean until receivers join. PIM Dense Mode (PIM-DM): Uses a legacy push (flood-and-prune) model—floods traffic everywhere every 3 minutes and prunes branches with no receivers (inefficient for enterprise WANs).

Rendezvous Point (RP) & RP Discovery (Static, Auto-RP, BSR, Anycast)

RP (Rendezvous Point): A central meeting-point router in PIM Sparse Mode where multicast sources register (via unicast PIM Register from the First-Hop Router) and receivers join (via (*,G) PIM Joins from the Last-Hop Router) before switching to a direct Shortest-Path Tree (S,G). Static RP: Manually configured on every router (ip pim rp-address). Auto-RP: Cisco-proprietary dynamic RP election using 224.0.1.39 (Candidate-RP) and 224.0.1.40 (Mapping Agent). BSR (Bootstrap Router): Open-standard (RFC 5059) dynamic RP election carried inside hop-by-hop PIM messages (224.0.0.13). Anycast RP + MSDP: Multiple routers share the same loopback IP as RP for load sharing and fast failover, syncing active sources via MSDP (Multicast Source Discovery Protocol).

IGMPv2 vs. IGMPv3 & Source-Specific Multicast (SSM)

IGMP (Internet Group Management Protocol): Layer 3 protocol used by hosts to join multicast groups on their local subnet. IGMPv2: Supports group-specific Leave messages (224.0.0.2) to stop traffic quickly instead of waiting for timeout. IGMPv3: Adds source filtering (INCLUDE/EXCLUDE lists) to 224.0.0.22, enabling SSM (Source-Specific Multicast — 232.0.0.0/8) where receivers join (S,G) directly without needing an RP or shared tree.

RPF (Reverse Path Forwarding) & L2 Multicast MAC Mapping

RPF (Reverse Path Forwarding): Loop-prevention check where a router verifies that an incoming multicast packet arrived on the exact interface it would use to reach the unicast source IP (or RP IP); if not, the packet is dropped. IPv4 Multicast MAC Mapping: Maps multicast IPs (224.0.0.0/4) to Ethernet MAC 01:00:5e:00:00:00 + the low-order 23 bits of the IP; dropping 5 bits creates a 32-to-1 overlap (32 multicast IPs share one MAC).

Quality of Service (QoS)

QoS Marking: DSCP, PHB, EF, AF, CS & 802.1p CoS

QoS (Quality of Service): Manages bandwidth, delay, jitter, and packet loss across congested links. DSCP (Differentiated Services Code Point): 6-bit field (0–63) inside the IPv4/IPv6 header defining PHB (Per-Hop Behavior). EF (Expedited Forwarding — DSCP 46): Low-latency priority behavior for VoIP audio. AF (Assured Forwarding — AFxy): Four traffic classes (x=1–4) with three drop-precedence levels (y=1 low to 3 high), such as AF41 (DSCP 34) for interactive video. CS (Class Selector — CS0–CS7): Multiples of 8 (e.g., CS3 = 24 for call signaling) for backward compatibility with legacy 3-bit IP Precedence. CoS (Class of Service): 3-bit (0–7) Layer 2 priority field inside an 802.1Q Ethernet trunk tag (CoS 5 maps to voice).

Policing vs. Shaping, LLQ, CBWFQ & WRED

MQC (Modular QoS CLI): Three-step Cisco configuration framework: class-map (match traffic) → policy-map (mark, police, shape, or queue) → service-policy (apply to interface). Policing: Strictly enforces a rate limit (CIR) by immediately dropping or re-marking excess packets without buffering (used at ingress/SP edges). Shaping: Buffers excess packets in memory to smooth outbound bursts to the contracted rate (introduces delay instead of drops; used on WAN egress). LLQ (Low Latency Queuing): Adds a strict priority queue (with built-in policer) on top of CBWFQ (Class-Based Weighted Fair Queuing) so voice is served first without starving data queues. WRED (Weighted Random Early Detection): Proactively drops lower-priority TCP packets before queues hit 100% full to avoid TCP global synchronization.

Layer 2 EtherChannel, Trunking & Time Sync

EtherChannel (LACP vs. PAgP), DTP, NTP, PTP & SSO

EtherChannel: Bundles 2–8 physical Ethernet links into one logical Port-Channel for load-balanced bandwidth and sub-second link failover. LACP (Link Aggregation Control Protocol — IEEE 802.3ad / 802.1AX): Open-standard negotiation using active (initiates) and passive (listens) modes. PAgP (Port Aggregation Protocol): Cisco-proprietary negotiation using desirable (initiates) and auto (listens) modes. DTP (Dynamic Trunking Protocol): Cisco protocol that negotiates 802.1Q trunking (dynamic desirable / dynamic auto). NTP vs. PTP: NTP (Network Time Protocol — UDP 123) syncs device clocks to millisecond accuracy; PTP (Precision Time Protocol — IEEE 1588) uses hardware timestamps for sub-microsecond accuracy. SSO (Stateful Switchover): High-availability redundancy where a standby supervisor maintains synced Layer 2/control-plane state for rapid failover.

IPv4 Multicast MAC Mapping (32-to-1 Overlap)

IPv4 multicast addresses (224.0.0.0/4) map to Ethernet MAC prefix 01:00:5e:00:00:00 plus the low-order 23 bits of the IPv4 address. Because 5 bits (28 multicast host bits − 23 MAC bits) are dropped, 32 IPv4 multicast addresses share the exact same Layer 2 MAC address.

Quality of Service (QoS)

QoS Marking Acronyms (DSCP, PHB, EF, AF, CS, CoS, ToS, MQC)

QoS: Quality of Service. DSCP: Differentiated Services Code Point (6-bit IP header field, values 0–63). PHB: Per-Hop Behavior. EF: Expedited Forwarding (DSCP 46 — voice). AF: Assured Forwarding (AFxy where x = class 1–4, y = drop precedence 1–3). CS: Class Selector (backward-compatible with legacy 3-bit IP Precedence). CoS: Class of Service (3-bit IEEE 802.1p field inside an 802.1Q VLAN tag). ToS / MQC: Type of Service / Modular QoS CLI.

Policing vs. Shaping & Congestion Management

Policing: Enforces a strict rate limit (CIR/Bc/Be) by immediately dropping or re-marking excess packets (no buffering; causes TCP retransmissions). Shaping: Buffers excess packets in a queue to smooth outbound bursts to the contracted rate (adds delay/jitter instead of drops). LLQ (Low Latency Queuing): Adds a strict priority queue (for voice) to CBWFQ (Class-Based Weighted Fair Queuing). WRED: Weighted Random Early Detection (drops lower-priority TCP packets before queues fill completely).

Layer 2 EtherChannel, Trunking & Time Sync

EtherChannel & Time Acronyms (LACP, PAgP, DTP, VTP, NTP, PTP, NAT, PAT, SSO)

LACP: Link Aggregation Control Protocol (IEEE 802.3ad / 802.1AX — modes active / passive). PAgP: Port Aggregation Protocol (Cisco proprietary — modes desirable / auto). DTP / VTP: Dynamic Trunking Protocol / VLAN Trunking Protocol. NTP / PTP: Network Time Protocol (UDP 123, millisecond accuracy) / Precision Time Protocol (IEEE 1588, sub-microsecond accuracy). NAT / PAT: Network Address Translation / Port Address Translation. SSO: Stateful Switchover (supervisor redundancy).
